# LeetCode 206. 反转链表

## 题目核心

给定单链表的头节点 `head`，将链表的指针方向全部反转，并返回反转后的新头节点。

例如：

```text
输入：1 -> 2 -> 3 -> null
输出：3 -> 2 -> 1 -> null
```

反转时不能只交换节点值，真正需要改变的是每个节点的 `next` 指针。

## 当前解法：迭代反转

当前 `206/206.js` 使用三个变量完成原地反转：

```js
var reverseList = function (head) {
  let pre = null;
  let next = null;

  while (head != null) {
    next = head.next;
    head.next = pre;
    pre = head;
    head = next;
  }

  return pre;
};
```

三个变量分别表示：

- `head`：当前正在处理的节点。
- `pre`：已经反转完成的链表头节点。
- `next`：提前保存的下一个节点，防止原链表后半段丢失。

## 反转过程

假设当前链表为：

```text
1 -> 2 -> 3 -> null
```

第一次循环：

```text
保存 next = 2
修改 1.next = null

已反转：1 -> null
待处理：2 -> 3 -> null
```

第二次循环：

```text
保存 next = 3
修改 2.next = 1

已反转：2 -> 1 -> null
待处理：3 -> null
```

第三次循环后：

```text
3 -> 2 -> 1 -> null
```

此时 `head` 为 `null`，而 `pre` 指向新的头节点 `3`，所以返回 `pre`。

## 为什么必须先保存 next

执行下面这句以后：

```js
head.next = pre;
```

当前节点会改为指向前一个节点。如果没有提前保存原来的 `head.next`，就无法继续访问尚未处理的链表。

因此循环中的操作顺序不能随意交换：

```text
保存后继节点 -> 反转当前指针 -> 移动 pre -> 移动 head
```

## 复杂度

- 时间复杂度：`O(n)`，每个节点只处理一次。
- 空间复杂度：`O(1)`，只使用固定数量的指针变量。

## 递归写法

也可以先递归反转后半部分，再把当前节点接到末尾：

```js
var reverseList = function (head) {
  if (head == null || head.next == null) {
    return head;
  }

  const newHead = reverseList(head.next);
  head.next.next = head;
  head.next = null;
  return newHead;
};
```

递归写法的时间复杂度仍为 `O(n)`，但递归调用栈需要 `O(n)` 空间。链表很长时，迭代写法更安全。
